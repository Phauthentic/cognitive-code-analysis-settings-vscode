# Changelog

## 0.1.0

- Initial release.
- Cognitive complexity diagnostics for PHP methods above the `scoreThreshold` of phpcca.
- Analysis of unsaved buffers, on open, on save or while typing.
- Settings `phpcca.enable`, `phpcca.executable`, `phpcca.configFile`, `phpcca.runOn` and `phpcca.debounceMs`.
